# Ancient Greek Verb Lab — Σχολική έκδοση πλήρους κλίσης

Στατική εκπαιδευτική εφαρμογή για την αναγνώριση, τη μελέτη και την εξάσκηση στους ρηματικούς τύπους της Αρχαίας Ελληνικής. Η σχολική έκδοση επαναφέρει την αναλυτική λογική της προ-Kalos εφαρμογής και οργανώνει την πλήρη κλίση γύρω από τα εγχειρίδια της Α΄ Λυκείου, χωρίς να περιορίζει την ευρύτερη αναγνώριση τύπων.

## Βασικές λειτουργίες

- **Αναγνώριση τύπων:** πολυτονική αναζήτηση ανεκτική ως προς τόνους, πνεύματα, υπογεγραμμένες και τελικό σίγμα. Το Kalos διατηρείται ως συμπληρωματικό finite επίπεδο αναγνώρισης.
- **Πλήρης κλίση:** προβάλλονται κατά προτεραιότητα τα χειροκίνητα και προ-Kalos παραδείγματα των λημμάτων που αντιστοιχίζονται με το σχολικό σώμα.
- **Προσωπικοί τύποι:** χρόνοι, φωνές, εγκλίσεις, πρόσωπα και αριθμοί, μαζί με τον δυϊκό όπου είναι καταχωρισμένος.
- **Μη προσωπικοί τύποι:** απαρέμφατα και αναλυτική κλίση μετοχών κατά χρόνο, φωνή, γένος, αριθμό και πτώση.
- **Λεξικογραφικά μεταδεδομένα:** νεοελληνική σημασία, αρχικοί χρόνοι και συντηρητικά διατυπωμένη ετυμολογική ή μορφολογική σημείωση, όταν υπάρχει ασφαλής πληροφορία.
- **Σχολική τεκμηρίωση:** επισήμανση του εγχειριδίου ή των εγχειριδίων στα οποία εντοπίζεται ο κανονικοποιημένος τύπος.
- **Εξάσκηση:** αναγνώριση, παραγωγή τύπου, σημασία και σχολική πηγή, με επίπεδα δυσκολίας και ομαδικό παιχνίδι τάξης.

## Σχολικό σώμα

Η συμπαγής βάση περιλαμβάνει **11.530 μοναδικά κανονικοποιημένα λεκτικά κλειδιά** από επτά σχολικά τεύχη:

1. *Αρχαίοι Έλληνες Ιστοριογράφοι* — βιβλίο μαθητή.
2. *Ανθολόγιο Γλωσσικής Διδασκαλίας* — βιβλίο μαθητή/μαθήτριας.
3. *Ανθολόγιο Γλωσσικής Διδασκαλίας* — τετράδιο εργασιών.
4. *Ξενοφών, Ελληνικά* — βιβλίο μαθητή/μαθήτριας.
5. *Ξενοφών, Ελληνικά* — τετράδιο εργασιών.
6. *Λυσίας, Κατά Ερατοσθένους* — βιβλίο μαθητή/μαθήτριας.
7. *Λυσίας, Κατά Ερατοσθένους* — τετράδιο εργασιών.

Το παλαιό βιβλίο εκπαιδευτικού χρησιμοποιήθηκε μόνο ως παράλληλη διδακτική πηγή και δεν αποτελεί χωριστή εγγραφή του manifest.

Το αποθετήριο δεν αναπαράγει συνεχές κείμενο ή σελίδες των σχολικών βιβλίων. Αποθηκεύει μόνο κανονικοποιημένα κλειδιά αντιστοίχισης και ένα bitmask εγχειριδίου. Κατά συνέπεια, η παρούσα συμπαγής έκδοση τεκμηριώνει την **πηγή σε επίπεδο βιβλίου**, όχι την ακριβή σελίδα PDF.

## Τεχνική δομή

- `index.html`: διεπαφή τεσσάρων ενοτήτων — Αναγνώριση, Πλήρης κλίση, Εξάσκηση και Πληροφορίες.
- `style.css`: προσαρμοστική και εκτυπώσιμη εμφάνιση.
- `viewer.js`: loader που φορτώνει, αποσυμπιέζει και ελέγχει την ακεραιότητα των ενεργών πακέτων.
- `data/school_corpus_manifest.js`: μεταδεδομένα, πηγές, ενεργά shards, πλήθος εγγραφών και SHA-256.
- `data/school_corpus_compact_01.js`–`04.js`, `05a.js`, `05b.js`, `06.js`: επτά shards του σχολικού δείκτη.
- `data/app_bundle_packed_01.js`–`04.js`: τέσσερα shards του κώδικα της σχολικής εφαρμογής.
- `data/school_corpus_packed_01.js`–`02.js`: μικρά compatibility bootstraps για την υφιστάμενη σειρά scripts του `index.html`· δεν περιέχουν πλέον corpus payload.
- `scripts/validate-release.mjs`: έλεγχος manifest, base64, gzip, hashes, JSON, διπλοεγγραφών, JavaScript, HTML, CSS και προσωρινών αρχείων.

Το σχολικό σώμα και ο κώδικας της εφαρμογής ελέγχονται κατά τη φόρτωση με SHA-256. Ο ίδιος έλεγχος εκτελείται στο GitHub Actions για κάθε pull request.

## Τοπική εκτέλεση

Η εφαρμογή πρέπει να ανοίγει μέσω τοπικού HTTP server και όχι απευθείας ως `file://`:

```bash
python -m http.server 8000
```

Έπειτα άνοιξε `http://localhost:8000`.

## Έλεγχος έκδοσης

```bash
node scripts/validate-release.mjs
```

Η επιτυχής έξοδος επιβεβαιώνει, μεταξύ άλλων:

- 11.530 μοναδικές σχολικές εγγραφές από 7 πηγές·
- ακριβή αποσυμπίεση και SHA-256 του σχολικού σώματος·
- ακριβή αποσυμπίεση και συντακτική εγκυρότητα του app bundle·
- συνέπεια manifest και ενεργών shards·
- απουσία παλαιών ή διεφθαρμένων payloads.

## Δηλωμένοι περιορισμοί

- Η πληρότητα κάθε παραδείγματος εξαρτάται από τα ελεγμένα χειροκίνητα και παραγόμενα datasets του αποθετηρίου.
- Κενό κελί σημαίνει «δεν υπάρχει στο τρέχον ελεγμένο παράδειγμα» και όχι κατ’ ανάγκην «ο τύπος είναι αδύνατος στην Αρχαία Ελληνική».
- Τα λήμματα που υπάρχουν αποκλειστικά στο finite-only στρώμα Kalos αναγνωρίζονται, αλλά δεν παρουσιάζονται ως δήθεν πλήρη παραδείγματα.
- Σπάνιοι, διαλεκτικοί, ποιητικοί και κειμενοκριτικά αμφισβητούμενοι τύποι απαιτούν χωριστό φιλολογικό έλεγχο.
