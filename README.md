# Ancient Greek Verb Lab

Στατική εκπαιδευτική εφαρμογή για την αναγνώριση, τη μελέτη και την εξάσκηση στους ρηματικούς τύπους της Αρχαίας Ελληνικής.

## Σχολική έκδοση

Η σχολική έκδοση οργανώνει την εφαρμογή γύρω από τα συνημμένα εγχειρίδια της Α΄ Λυκείου:

- *Αρχαίοι Έλληνες Ιστοριογράφοι*·
- *Ανθολόγιο Γλωσσικής Διδασκαλίας* και Τετράδιο Εργασιών·
- *Ξενοφών, Ελληνικά* και Τετράδιο Εργασιών·
- *Λυσίας, Κατά Ερατοσθένους* και Τετράδιο Εργασιών·
- το αντίστοιχο παλαιό βιβλίο εκπαιδευτικού ως παράλληλο διδακτικό υλικό.

Η εφαρμογή παρέχει:

1. **Αναγνώριση τύπων** με αναζήτηση ανεκτική σε τόνους, πνεύματα, υπογεγραμμένες και τελικό σίγμα. Το Kalos παραμένει συμπληρωματική πηγή αναγνώρισης.
2. **Πλήρη κλίση σχολικών λημμάτων**, με πρόσωπα, αριθμούς, εγκλίσεις, χρόνους και φωνές που υπάρχουν στα διαθέσιμα παραδείγματα, καθώς και απαρέμφατα και αναλυτικά κλιμένες μετοχές.
3. **Λεξικογραφικά μεταδεδομένα**, όπως νεοελληνική σημασία, αρχικοί χρόνοι και ετυμολογική ή μορφολογική σημείωση όταν αυτή μπορεί να δοθεί με ασφάλεια.
4. **Σχολικές εμφανίσεις**, με αντιστοίχιση τύπου, εγχειριδίου και σελίδας PDF.
5. **Εξάσκηση και παιχνίδι τάξης**, με ερωτήσεις αναγνώρισης, παραγωγής τύπου, σημασίας και σχολικής πηγής.

## Δομή

- `index.html`: διεπαφή της εφαρμογής.
- `style.css`: προσαρμοστική και εκτυπώσιμη εμφάνιση.
- `viewer.js`: ελαφρύς φορτωτής της σχολικής λειτουργίας.
- `data/`: βασικά μορφολογικά bundles, Kalos finite shards και το σχολικό σώμα.
- `data/school_corpus_manifest.js`: μεταδεδομένα, βιβλία και ενεργά αρχεία του σχολικού σώματος.
- `data/school_corpus_packed_01.js`–`02.js`: συμπιεσμένος σχολικός δείκτης.
- `data/viewer_school_packed_01.js`–`02.js`: συμπιεσμένος κώδικας της σχολικής διεπαφής.
- `scripts/validate-release.mjs`: στατικός έλεγχος πακέτου, αποσυμπίεσης και συντακτικής εγκυρότητας.

Τα πλήρη κείμενα ή οι σελίδες των σχολικών βιβλίων δεν ενσωματώνονται στο αποθετήριο. Το σχολικό σώμα περιέχει μόνο τα απολύτως αναγκαία ευρετηριακά δεδομένα για τη σύνδεση τύπων, λημμάτων και σελίδων.

## Τοπική εκτέλεση

Η εφαρμογή πρέπει να ανοίγει μέσω τοπικού HTTP server και όχι απευθείας ως `file://`:

```bash
python -m http.server 8000
```

Έπειτα άνοιξε `http://localhost:8000`.

## Έλεγχος έκδοσης

```bash
node scripts/validate-release.mjs
```

Ο έλεγχος επιβεβαιώνει:

- ότι υπάρχουν όλα τα αρχεία που αναφέρονται από το HTML και το manifest·
- ότι τα packed school corpus και viewer ενώνονται και αποσυμπιέζονται·
- ότι ο αποσυμπιεσμένος κώδικας είναι συντακτικά έγκυρος·
- ότι το πλήθος των σχολικών εγγραφών συμφωνεί με το manifest·
- ότι δεν έχουν παραμείνει προσωρινά ή πειραματικά shards.

Η ίδια διαδικασία εκτελείται αυτόματα στο GitHub Actions για κάθε pull request.
